# VNUK Observatory

Самостоятельный index.html для Resistance Tools / TON Storage. Основа: TON Observatory Template 1.2.0.

## Сборка

```sh
python3 -m scripts.refresh_observatory
python3 build.py
python3 verify.py
python3 -m unittest discover -s tests -p 'test_*.py'
node --test tests/*.test.cjs
```

В HTML встроены стили, JavaScript, изображения и проверенный снимок данных. Для просмотра сохранённого снимка внешние ресурсы не нужны. Внешние ссылки ведут к проекту, обозревателям и DeDust.

## Данные

Контракт и decimals проверены через TonAPI. Прямой пул VNUK/TON проверен через get_assets. Native и VNUK vault проверены через get_asset. Ответы сохранены в evidence/.

TonAPI выдаёт события этого пула как SmartContractExec. dedust_native.py сопоставляет успешные DedustSwapExternal и DedustPayoutFromPool: один query ID, ожидаемые vault, один получатель, отсутствие следующего пула. Неоднозначные и маршрутизированные обмены пропускаются. Это ограниченное покрытие прямых операций, а не всех операций токена. Известные примеры и отрицательные случаи проверяются тестами.

График — оценка капитализации по текущему totalSupply и цене успешной сделки выбранного пула. USD использует исторический курс TON. Незавершённая глубина истории отмечается в интерфейсе. Отсутствие источников заморозки/стейкинга не означает нулевые суммы; эти показатели не подключены. Метки кошельков дополняются постепенно. Нулевые сжигания относятся только к проверенному интервалу, а не ко всей истории.

## Обновления и публикация

Исходники: https://github.com/Freebielife/VNUK. Сайт проверяет data/snapshot.json из основной ветки каждые 5 минут и сохраняет предыдущий корректный снимок при ошибках.

GitHub Actions собирает данные, проверяет и пересобирает index.html при изменении исходников, ручном запуске и по расписанию 17,47 * * * * (UTC). Плановые задания GitHub могут задерживаться. Общий Cloudflare-планировщик не изменяется.

Публикация в TON Storage выполняется отдельно: загрузите проверенный index.html в Resistance Tools / TON Storage. После публикации HTML подгружает совместимые свежие снимки из репозитория; для изменений интерфейса нужен новый index.html.
